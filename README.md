# BitPull downloads

Installers of the BitPull desktop app for macOS, Windows and Linux.
Get the latest version from the [Releases](https://github.com/SamuealPK/bitpull-releases/releases/latest) page or from the BitPull website.

- **macOS:** open the `.dmg` and drag BitPull to Applications. The first time, right-click the app and choose Open.
- **Windows:** run the `-setup.exe` installer. If SmartScreen appears, choose More info → Run anyway.
- **Linux:** make the `.AppImage` executable and run it.

The source code of BitPull is private; this repository only hosts the installers.
